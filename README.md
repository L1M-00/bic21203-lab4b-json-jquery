## Files Included
- `books.json` - JSON dataset containing book details.
- `books.html` - Uses native JavaScript `fetch()` to load and display data from `books.json`[cite: 6].
- `jquery-dom.html` - Demonstrates DOM updates and click events using jQuery 4.0.0[cite: 6].

## Setup Instructions
1. Download or clone this repository to your local computer.
2. Open the folder in VS Code.
3. Right-click `books.html` and select **Open with Live Server** (running via a local server is required so `fetch()` can read `books.json` without browser CORS errors)[cite: 6].
4. Open `jquery-dom.html` in any web browser (or via Live Server) and click the button to test the alert[cite: 6].
